# PerfLoop's design (moved)

PerfLoop moved to its own repository on 4 November 2026: https://github.com/MarvinAmador7/perfloop (MIT). Its code,
these design documents (under `docs/design/`) and their later changes live there now. capcomd depends on it by URL
(`apps/menubar/app/Package.swift`); the capcomd adapter, `deskbench`, stays here (apps/menubar/app/DESKBENCH.md,
PROGRAM.md).

The files in this folder are the design as it stood when PerfLoop lived in `tools/perfloop`, kept for the history of
the desktop app's performance work. `probes/` holds the feasibility probes run from this repo.
