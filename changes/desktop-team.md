# CHANGELOG

- Desktop app: **Team**. The Team button in the sidebar's foot (and on the folded rail) lists your agent profiles by
  project, then "All projects" for your own, each with its bot and what it does (plans, leads, builds, reviews). Pick
  one to open it as a pane: rename it and change its bot in place, give it a task from the same composer as Home (a
  worker profile starts a run of that profile; a planner does where capcomd can start a run with a planner), read and
  edit its SOUL.md, open its settings row to change any value (saved as you change it, with where each value comes from
  and Reset), see its recent work, and for an installed profile check for updates or show it in Finder. Splits (⌘D)
  and expand (⇧⌘↩) work as for agents. Parts whose routes your capcomd doesn't have yet are left out.
