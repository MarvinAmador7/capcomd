# Spec

Every agent provider declares its own environment variable families, decided by the owner (2026-11-10; §7.3, §6.6.7, §10.3): `describe().envPrefixes` (optional, additive), the name prefixes matching `ENV_PREFIX` (`^[A-Z][A-Z0-9_]*_$`, each once) where the provider's CLI reads its credential, login and settings; agent-claude declares `ANTHROPIC_`, `CLAUDE_`, agent-codex `OPENAI_`, `CODEX_`, agent-fx `AI_GATEWAY_`, `VERCEL_`, `FX_`. `reservedEnvName`, `kernelVariable` and `hostCheckEnv` are the kernel's own families plus every provider's (`src/plugins/env-families.ts`) instead of hand-kept lists, the same names as before for the three built-ins; a built-in's families stay when its plugin is disabled. A provider's families only add protection: `ctx.seams.agent` throws `invalid` for a list that isn't one of families or a prefix that would take in a kernel family (one a kernel prefix or variable starts with: `NPM_`, `GITHUB_`), which the kernel answers through the new optional `ContextOptions.refuseSeam` (`HostOptions.sinks`); the agent conformance suite checks the list's shape. No hook, route or contract shape changes.
