# CHANGELOG

- Desktop app: fx is a harness of its own. Agents, profiles and Team rows that run on fx show fx's mark (a plain "fx"
  monogram) and its name, where they showed nothing before. A Team profile on fx offers fx's effort levels in its model
  chip. Settings › Accounts has an fx section with its login in each place, and Settings › Runs lists fx's version in
  the agent environment.
- Desktop app: an agent harness the app doesn't know yet, such as a plugin's, shows a generic mark and its name instead
  of disappearing.
