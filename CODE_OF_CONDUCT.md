# Code of Conduct

capcomd follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful and constructive, assume good faith, and keep discussions about the work. Harassment,
personal attacks, discriminatory language and publishing others' private information are not acceptable, in the
repository, its issues, pull requests and discussions, or anywhere you represent the project.

## Reporting

Report unacceptable behavior privately to the maintainer, Marvin Amador Campos
([@MarvinAmador7](https://github.com/MarvinAmador7)), using the contact details on that GitHub profile. Reports
are handled confidentially. The maintainer may remove, edit or reject comments, commits, code, issues and other
contributions that break this code, and may ban contributors from the project temporarily or permanently, following
the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
