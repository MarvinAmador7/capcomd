# capcomd-tui

A terminal debugger for capcomd runs, built with Ink and [termcn](https://www.termcn.dev) components.
It lives in its own package and reads only what the `capcomd` CLI prints, so it never imports `src/`.

```bash
cd apps/tui && bun install
bun run start                            # demo fixture (synthetic 3-task run)
bun run start --fixture task-timeout     # real trace: claude-code timed out after 20 min
bun run start --list                     # all fixtures
bun run start --run <runId>              # live: polls trace/events/tree every 2 s
bun run start --view rollups             # open on a view
bun run typecheck && bun test
```

`--run` shells out to `bun <repo>/src/cli/index.ts`. Set `CAPCOMD_BIN="capcomd"` to use an installed CLI instead.

## Views

| Key | View | What it answers | Keys |
|---|---|---|---|
| 1 | Live | Who's running, what it has spent against its budget, what just happened | |
| 2 | Waterfall | Where the time went. Spans are nested, and repeated siblings are folded (`sandbox.exec ×770`) | `j/k` · `enter` unfold · `z` fold all · `g/G` |
| 3 | Timeline | One lane per agent, showing agent, git, and sandbox time plus approval waits | `j/k` |
| 4 | Rollups | Wall time, cost, turns, and errors. Cost and turns per agent, time per span family, activity | |
| 5 | Events | The event log, filtered by family (run/plan/task/worker/agent/problems) and searchable | `f/F` · `/` · `esc` · `j/k` |
| 6 | Replay | Scrub a finished run: spans grow to the playhead and events appear as they happened | `space` · `←/→` · `[ ]` · `0` |

`1–6` or `tab` switches views and `q` quits.

Design notes: there is one accent color, used only for the current focus and for agent work. Green, amber, and red appear only when something succeeded, is waiting, or failed. Everything else is grey. Keyboard actions never animate. The only motion is the replay playhead, which moves linearly.

## Data sources

Adapters in `src/adapters/` accept every shape the CLI emits:

- **trace**: raw `.traces/<runId>.ndjson` or `capcomd trace <id> --json`. Orphan spans hang off a synthesized `relay.run` root, as `loadTrace()` does.
- **events**: the `capcomd run --json` stream (`{type, ts, …}`), `events --json` pages (`{events:[{entity, at, event}]}`), and `--follow --json` lines. `{ok:false,error}` envelopes become `cli.error` events.
- **tree**: `capcomd tree <id> --json`. Without a tree, agents are inferred from `agent.*` spans (`agent.cost_usd`, `agent.turns`, and duration, summed per task).

## Screenshots

`FORCE_COLOR=3 bun run shots [dir]` writes `.ansi` and `.html` renders of every view (via ink-testing-library). Any headless browser can turn the HTML into PNGs.

## termcn

The registry is configured in `components.json`:

```json
{ "registries": { "@termcn": "https://termcn.dev/r/{name}.json" } }
```

Installed with `npx shadcn@latest add @termcn/ink/bar-chart @termcn/ink/sparkline @termcn/ink/badge` into `src/components/ui/`, with their hooks and lib. The app passes its own theme (`src/theme.ts`) through termcn's `ThemeContext`. Add more with `npx shadcn@latest add @termcn/ink/<name>`.

**MCP (optional, for your editor):** run `npx shadcn@latest mcp init` in `apps/tui`, pick your client (Cursor, Claude Code, VS Code…), then enable the server in that client. The shadcn MCP server can then browse and install `@termcn/*` items from this `components.json`. See https://www.termcn.dev/docs/mcp.

## Waterfall icons (`--icons glyph|nerd|minimal|none`, default `glyph`)

Each row shows a kind icon before the name and a status mark after the duration. Within a set, no symbol has two meanings. Kind icons are grey, and only the selected row's icon takes the accent. Status uses the semantic colors, and `ok` is drawn faint.

| kind | glyph | nerd | minimal |
|---|---|---|---|
| agent | ◆ | 󰚩 | A |
| llm / turn | ◇ | 󰧑 | L |
| tool | ▪ |  | T |
| git | ⎇ |  | G |
| sandbox | ▸ |  | S |
| approval | ◷ | 󰔟 | W |
| run / plan | ◎ |  | R |
| actor / transition | · |  | · |
| status ok · error · wait · running | ✓ ✕ ◌ ● |     | • (colored) |

`nerd` needs a Nerd Font v3. Without one, the icons show as empty boxes. `FORCE_COLOR=3 bun scripts/icon-shots.tsx` renders all three.
