Your agent runs the crew.You decide what lands.

You ask once. The run is durable: agents keep working when your agent's session ends, a crash or a restart resumes where it stopped, and every merge happens exactly once.

On your Mac, a native menu bar app shows every run and puts each approval one keystroke away. The app is macOS only and built from source for now; capcomd itself runs on macOS and Linux.

Ask

Tell your coding agent the outcome, or type it into the menu bar. You don't run orchestration commands by hand.
