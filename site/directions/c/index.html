From ask to merge

You ask for the outcome.

Tell your coding agent, or type the goal into the menu bar. You don't run orchestration commands by hand.

Your agent spawns the crew.

A planner splits the work. Claude Code and Codex agents run in parallel, each in its own VM, on its own branch.

Your checks run on every branch.

Merged with the latest target, in a throwaway VM. Agents pick a check by name and can never write their own.

Another agent reviews it.

A read-only reviewer reads each change against the acceptance criteria. Checks and review must both pass.

You approve. It lands once.

Only the exact commit that passed merges, exactly once. Merges into protected branches wait for you.
