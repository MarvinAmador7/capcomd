Send in the swarm

capcomd turns your coding agent into the orchestrator. It spawns a team of Claude Code and Codex agents in parallel, each in its own VM and branch, and lands only work that passed your checks and another agent's review.

Free and open source under MIT. An early release (0.6): expect changes between minor versions.

brew install MarvinAmador7/tap/capcomd

How a run plays out

You ask once, in plain words. Your agent plays the rest with capcomd's moves: spawn, await, verify, merge. Your gates decide what lands.

Ask

Tell your coding agent the outcome you want. You don't run orchestration commands by hand.

You, to your agent
Use capcomd to fix the failing tests in src/: one worker per file, each verified and reviewed, then merged.

Swarm

Your agent splits the work and spawns Claude Code and Codex agents that run in parallel, each in its own isolated VM on its own branch. They can't touch each other's work, or your machine.

Verify

Checks you named run on each branch merged with the latest target, in a throwaway VM. Agents pick a check by name; they can never write their own.

Review

A separate, read-only reviewer agent reads each change against the acceptance criteria. Checks and review must both pass; a missing or garbled verdict is a fail.

PassThe fix matches the failing test and changes nothing else.

Merge

Only the exact commit that passed lands, and every merge happens exactly once. Merges into protected branches wait for you.
